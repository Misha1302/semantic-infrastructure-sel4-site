02 / SYSTEM SHAPE

A runtime graph with a separate control plane

Invocation / Action and Streaming are sibling workload planes. Authority, real-time/temporal guarantees, and provenance cross the stack. Planning is not the runtime path.

03 / SEMANTIC OBJECT

One object carries the contract the machine lacks

The semantic layer names the entity, state categories, operations, streams, authority, and timing requirements directly. The lower system realizes them; it does not invent them.

06 / WALKTHROUGH B

Motor#4 makes time part of correctness

Real-time is not a third execution fabric. It is a temporal contract that constrains an Invocation / Action or a stream from semantic requirement to runtime evidence.

08 / ORTHOGONAL AXES

Do not collapse workload shape into system guarantees

Invocation and Streaming answer “what shape is the work?”. Authority, Real-Time, and Provenance answer different questions that can apply to either workload.

09 / WHY seL4

A precise lower authority substrate

seL4 gives the project capability-based kernel mechanisms, isolation, IPC, and strong machine-checked verification results for specific kernel configurations. It does not prove the project's higher-level semantics.

DOMAIN MEANING Refrigerator · Motor · ownership · deploy · emergency stop

KERNEL MECHANISMS capabilities · endpoints · address spaces · memory · IPC · scheduling contexts
