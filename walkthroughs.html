Walkthroughs

Two objects, two workloads — with cross-cutting contracts.

A refrigerator demonstrates a finite Invocation plus an independent stream. A motor emergency stop shows how a real-time contract can constrain an Invocation without becoming a third execution fabric.

Refrigerator#17 command path

Browser
  → Refrigerator#17.setTemperature(4)
  → authenticated SubjectContext
  → semantic authorization + residual guards
  → Invocation / Action
  → verified / installed authority-resource path
  → seL4 IPC
  → application / device
  → observable result + event

At the semantic layer the request names a domain object and method. The planner/runtime must determine the authorized low-level execution path. The target is to preserve least authority while keeping machine details out of the primary interface.

Independent telemetry path

device telemetry
  → Streaming plane
  → Refrigerator#17.temperature
  → browser / consumer

The stream is not the command transaction continuing forever. It has different semantics: rate, fan-out, ordering, loss, retention, and sampling concerns can apply without implying a hard deadline.

What leaves the critical path?

The strongest temporal design moves candidate planning, authority compilation, resource selection and schedulability/admission out of the deadline-critical path. A privileged installer then installs an accepted plan; runtime follows pre-authorized paths plus only the residual guards that cannot safely disappear.

Correctness can be two-dimensional: logical outcome + temporal constraint.
