Open research

Uncertainty is part of the architecture.

The goal of this page is not to decorate unknowns with confident boxes. It makes the questions explicit enough that experiments, proofs, or repository evidence can close them.

Semantic authority and topology

  1. How should semantic authority compile into least-authority capability topology?
  2. Which policy constraints can be structural and which require runtime checks?
  3. How should delegation, attenuation, and revocation interact with object lifecycle?
  4. How should object identity map to capability/resource lifecycle?

Transactions, streams, provenance

  1. What are the exact transaction failure/commit/rollback semantics?
  2. How should streams handle ordering, backpressure, sampling, retention, and loss?
  3. How should provenance be captured without contaminating deadline-critical paths?
  4. Which graph is authoritative for state, authority, and causal history under concurrent updates?

Temporal contracts and real-time

  1. Which temporal contracts belong directly in the semantic model?
  2. Where is the boundary between planning-time decisions and runtime checks?
  3. How are WCET assumptions obtained, represented, and validated?
  4. How should admission control, CPU reservation, memory reservation, blocking, and priority inversion be handled?
  5. How is temporal isolation provided between workloads?
  6. How can topology/policy changes avoid invalidating already-promised timing guarantees?
  7. How should mixed-criticality objects and operations be represented?

Refinement and verification

  1. Can semantic authority be refined or proved against concrete capability topology?
  2. Can temporal contracts be related to scheduling/resource configuration with machine-checkable guarantees?
  3. Which bounded end-to-end property is small enough to verify first yet important enough to matter?
  4. Does the architecture demonstrate a measurable property beyond a strong conventional distributed stack, or should the “new OS class” claim be narrowed?
Research discipline: if an experiment does not show a material difference, narrow the claim instead of adding layers.
